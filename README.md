### 一、 系统概述

本系统是一款专为教师设计的本地化轻量级桌面应用程序。程序支持通过U盘携带，在不同操作系统的教室电脑上独立运行（Windows/统信Linux）。系统主要用于管理学生平时成绩、动态设置计分规则、快速录入课堂表现，并支持教学日志和成绩汇总表的导出。

### 二、 核心数据库设计（SQLite）

系统底层采用 SQLite 轻量级数据库，包含以下五张核心数据表：

1. **班级管理表 (Classes)**
    - 字段：班级ID (主键)、班级名称、辅导员姓名、班级人数。
2. **学生信息表 (Students)**
    - 字段：学号 (主键)、姓名、班级ID (外键)。
3. **评分规则表 (ScoringRules)**
    - 字段：维度ID (主键)、维度名称、满分值、权重比例、排序号 (SortOrder，用于控制界面显示顺序)。
4. **教学日志表 (TeachingLogs)** _(原课程信息表)_
    - 设计目的：以“单次授课”为粒度记录数据，为后期导出教学日志提供完整依据。
    - 字段：场次ID (主键)、课程代码、课程名称、授课学时、授课日期、授课内容、授课教室、授课班级 (外键)。
5. **学生成绩详细总表 (ScoreDetails)**
    - 设计目的：作为底层唯一的数据持久化存储表，记录所有历史打分明细。
    - 字段：记录ID (主键)、场次ID (外键)、学号 (外键)、维度ID (外键)、实际得分、评分备注、录入时间。

### 三、 核心功能模块设计

#### 1. 课堂打分模块（核心交互界面）

- **场次选择**：提供下拉框或日历控件，让老师通过“授课日期”或“课程场次”快速定位并选择当次授课。
- **动态表格生成**：选定场次后，系统自动从内存中组装数据（读取该场次信息 + 该班级学生名单 + 评分规则），动态生成 `DataGridView` 表格。表格列包含：学号、姓名、动态评分维度（如出勤、作业等）、评分备注。
- **防丢失机制（临时存储）**：
    - 老师在 `DataGridView` 中填写的分数，在点击【保存入档】前，实时保存在内存的 `DataTable` 中。
    - 增加**本地缓存机制**：将未提交的打分数据序列化后临时保存在本地（如 JSON 文件或 SQLite 临时表）。若程序意外崩溃或关闭，下次打开时自动提示并恢复未保存的数据，避免重复劳动。
- **数据归档**：点击【保存入档】按钮后，程序遍历内存中的 `DataTable`，将数据拆分并批量写入【学生成绩详细总表】，同时清除临时缓存。

#### 2. 数据导入导出模块

- **Excel 导入**：支持从 Excel 批量导入学生基础信息（学号、姓名、班级），自动去重并写入数据库。
- **教学日志导出**：基于【教学日志表】，一键导出包含完整授课信息的 Excel 报表。
- **成绩汇总表导出**：基于【学生成绩详细总表】和【评分规则表】，自动计算各维度加权总分，导出包含学生学号、姓名、各维度得分、总分的完整成绩汇总表。

#### 3. 系统设置模块

- **评分维度设置**：提供可视化界面，允许老师自由添加、删除考核维度，设置满分值与权重，并通过拖拽或排序号调整维度在打分界面的显示顺序。
- **基础数据管理**：提供对班级、学生、教学日志记录的增删改查功能。

### 四、 非功能性需求（部署与运行）

- **极致便携**：采用 .NET 6/8 的 **Self-contained（独立模式）** 和 **Single-file（单文件发布）** 进行打包。
- **免环境运行**：生成的单一 `.exe` 文件内置了 .NET 运行时，U盘插入任意 Windows 电脑或统信 Linux 电脑（通过兼容引擎）均可双击直接运行，无需安装任何环境或数据库服务。
- **性能要求**：Excel 导入导出必须采用流式处理（如 MiniExcel 组件），确保在处理数百人班级数据时界面不卡顿、内存占用低。
